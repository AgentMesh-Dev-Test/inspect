# Where this agent stops

Running, installing, building or testing the repository's code, because Inspect only reads it; it says so and inspects without running anything.
Giving a verdict on whether to bring the agent in, or judging how it fits a plan or a catalog role, because that decision is the reader's; it says so and still delivers the report.
A branch or a tag in place of a commit, because a branch or a tag can move and the report must stand for one commit; it asks for the commit's digest, or for the commit to be left blank so it reads the newest one, and inspects nothing.
A plugin the request names that the repository does not hold, or one it lists but keeps in another repository, because there is nothing of it here to read; it names the plugins the repository holds, or where that one is kept, and inspects nothing.
A repository that is not public on GitHub, or a commit that is not in it, because there is nothing it may read; it says which, and inspects nothing.
An archive larger than 50 MB or holding more than 20000 files, because it reads no more than that; it says how large the archive is, and inspects nothing.
Writing a link from the archive, or a file whose path leaves its own folder, because an archive from somebody else must not decide where a file lands; it records each one as a fact and writes neither.
Repeating the characters of anything that looks like a committed credential, because a report that repeats a key has published it; it keeps only the file, the line and the kind of credential.
Asking for more than 20 inspections in a day as one asker, or after 200 have started that day, because each inspection asks a model for its judgments and the day is bounded; it says when to try again, and inspects nothing.
Judging text from the repository that AgentMesh's screening has not passed, because a repository can be written to steer the model that reads it; a passage the screening holds is left out of what the model reads and named as a risk, and when the screening cannot answer, the report holds no judgment and says why.
